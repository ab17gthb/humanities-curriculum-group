# Image Sources: Lesson 3, Jefferson's Republic and the Louisiana Purchase

All images are public domain as stated on their source pages, as recorded below. Downloads were made on October 22, 2026, and each file was verified as a valid image with PIL. Original downloads live in img/. Deck crops live in slides-build/img/ and were cropped from the downloads listed here. Document copies live in assets/.

## Thomas Jefferson, portrait by Rembrandt Peale (jefferson-peale.jpg; deck crop jefferson-port.jpg in slides-build/img/; document copy in assets/)
- Title: Thomas Jefferson
- Creator: Rembrandt Peale (1778 to 1860), as stated on the file page
- Date: 1800, as stated on the file page
- Holder: White House collection, per the file page (accession number 1962.395.1, White House, per the file page)
- Source: https://en.wikibooks.org/wiki/File:Thomas_Jefferson_by_Rembrandt_Peale,_1800.jpg (Wikimedia Commons file page as mirrored at en.wikibooks.org; the Commons file is File:Official Presidential portrait of Thomas Jefferson (by Rembrandt Peale, 1800).jpg)
- Public domain basis: The file page states that the work is a faithful photographic reproduction of a two-dimensional public domain work of art, that the author died in 1860 so the work is in the public domain, and that it was published before January 1, 1931. Used as a portrait crop in the deck and in the activity, Station 5.

## John Marshall, portrait by Henry Inman (marshall-inman.jpg; deck crop marshall-port.jpg in slides-build/img/; document copy in assets/)
- Title: John Marshall
- Creator: Henry Inman (1801 to 1846), as stated on the file page
- Date: 1832, as stated on the file page (a copy Inman made in 1832 of his 1831 original)
- Holder: Library of Virginia, Richmond, Virginia, per the file page (source/photographer: Virginia Memory)
- Source: https://en.wikibooks.org/wiki/File:John_Marshall_by_Henry_Inman,_1832.jpg (Wikimedia Commons file page as mirrored at en.wikibooks.org)
- Public domain basis: The file page states that the image is a faithful photographic reproduction of a two-dimensional public domain work of art and is therefore also considered to be in the public domain in the United States. The lesson captions the portrait with its 1832 date wherever it appears, so students do not mistake it for a likeness from 1803. Used as the section B divider image in the deck and in the activity, Station 2.

## Decatur Boarding the Tripolitan Gunboat (decatur-boarding.jpg; deck crops title-169.jpg and decatur-port.jpg in slides-build/img/; document copy in assets/)
- Title: Decatur Boarding the Tripolitan Gunboat, during the bombardment of Tripoli, 3 August 1804
- Creator: Dennis Malone Carter, as stated by the Naval History and Heritage Command and the White House Historical Association photo page
- Date: Painting of the 1804 action (nineteenth century), per the holder pages
- Holder: Naval History and Heritage Command (Photo # NH 44647-KN), per the Naval Historical Center iconic images listing
- Source: http://www.ibiblio.org/hyperwar/OnlineLibrary/photos/iconic/icon-ev/est-usn.htm (Naval Historical Center iconic images listing for the Barbary Wars, 1801 to 1805); image file obtained from Wikimedia Commons under the file name Decatur Boarding the Tripolitan Gunboat.jpg
- Public domain basis: The Naval Historical Center listing states that to the best of its knowledge the pictures referenced there are all in the Public Domain and can be freely downloaded and used for any purpose. The White House Historical Association photo page likewise credits the image as Public Domain, accessed via Wikimedia Commons. Used as the deck title image (16:9 crop), as the section D divider image in the deck (portrait crop), and in the activity, Station 4.

## Subjects for which no public domain image is used, recorded honestly
- A map of the Louisiana Purchase: the widely circulated modern map file on Wikimedia Commons (Louisiana Purchase.png and its derivatives) is licensed CC BY-SA 4.0 by its modern author, not public domain, so it is not used. No public domain period map was verified and downloaded for this build. The purchase's geography is taught in text and in the stat slide instead.
- The Louisiana Purchase treaty manuscript page: no verified public domain image file of the treaty page was obtained for this build, so no treaty image is used or implied. The treaty is represented by its audited bank text at Station 1 of the activity.
- William Marbury: no verified public domain portrait is used. Marbury's part of the lesson is taught through Marshall's opinion and the reading.
- The burning of the Philadelphia as a period print: a candidate print is held by the National Maritime Museum, Greenwich, but its reuse terms were not verified as public domain during this build, so it is not used. Decatur's action is represented by the Carter painting above, captioned as a painting of the 1804 action.
