## First flag raising on Iwo Jima (iwo-first-flag.jpg; deck crop iwo-port.jpg)
- Title: First Iwo Jima Flag Raising
- Creator: Staff Sergeant Louis R. Lowery, USMC, staff photographer for Leatherneck magazine
- Date: 23 February 1945
- Holder: Naval History and Heritage Command (photograph i04150c, as linked on the Commons file page), via Wikimedia Commons
- Source: https://commons.wikimedia.org/wiki/File:First_Iwo_Jima_Flag_Raising.jpg
- Public domain basis: Commons file page marks the image Public domain as a work of a United States Marine serving as an official photographer. This is a Marine Corps photograph of the first flag raising. The famous Associated Press photograph of the second flag raising, by Joe Rosenthal, is not a federal work and is not used anywhere in this lesson.
