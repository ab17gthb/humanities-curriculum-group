# Image Sources: Lesson 3, The Red Scare at Home

All images are public domain as stated on their Wikimedia Commons file pages. Downloads were made from Wikimedia Commons on October 21, 2026, and each file was verified as a valid image with PIL. Original downloads live in assets/. Deck crops live in slides-build/img/ and were cropped from the downloads listed here.

## Senator Joseph McCarthy, February 10, 1954 (mccarthy-1954.jpg; deck crop mccarthy-port.jpg)
- Title: Joseph McCarthy, Feb. 10, 1954
- Creator: Associated Press
- Date: February 10, 1954, as stated on the Commons file page
- Holder: Wikimedia Commons file, credit line on the file page reads Scan via Politico
- Source: https://commons.wikimedia.org/wiki/File:Joseph_McCarthy,_Feb._10,_1954.jpg
- Public domain basis: Commons file page marks the image Public domain. File page description records McCarthy telling reporters that he does not plan to change his rhetorical tactics, with his wife Jean McCarthy looking on.

- Title: Welch-McCarthy-Hearings
- Creator: United States Senate
- Date: June 9, 1954 (the hearing day shown, as stated in the file page description: Joseph Welch, left, with Senator Joe McCarthy, right, at the Senate Subcommittee on Investigations' McCarthy-Army hearings, June 9, 1954)

- Source: https://commons.wikimedia.org/wiki/File:Welch-McCarthy-Hearings.jpg
