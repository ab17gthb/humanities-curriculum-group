# Image Sources for Depression and New Deal Lesson 8, What the New Deal Changed and What It Did Not

All images are real public domain photographs or federal documents held by the Library of Congress or the National Archives and distributed through Wikimedia Commons. They were downloaded on October 21, 2026. Each download was opened and verified with PIL, and the principal photographs were inspected: the files show what their captions in the documents say they show. Deck versions are cropped to portrait (1046 by 1500) or to 16:9 for the title slide; no other alteration.

## 1. norris-shovel.jpg (deck title and portrait crop; activity, File 2)

- Title: TVA shovel at work on roadway at Norris Dam site
- What it shows: A power shovel at work on a roadway at the Norris Dam construction site, Tennessee Valley Authority.
- Creator: Lewis Hine
- Date: October 30, 1933
- Repository: National Archives and Records Administration, National Archives ID 532696, via Wikimedia Commons, file "TVA shovel at work on roadway at Norris Dam site, NARA 532696"
- Source URL: https://commons.wikimedia.org/wiki/File:%22TVA_shovel_at_work_on_roadway_at_Norris_Dam_site.%22_-_NARA_-_532696.jpg
- Public domain basis: Photograph held by the National Archives from a United States federal project; the Commons file page tags it Public domain as a work of the United States federal government.

## 2. signing-ssa.jpg (reading figure; deck portrait crop)

- Title: Roosevelt Signs the Social Security Act
- What it shows: President Roosevelt signing the Social Security Act on August 14, 1935, with members of Congress standing behind him.
- Creator: Photographer not credited on the Commons file page; the file is distributed by Social Security Online, the Social Security Administration history archive
- Date: August 14, 1935
- Repository: Library of Congress, Prints and Photographs Division, digital ID cph.3c23278, via Wikimedia Commons, file "Signing Of The Social Security Act.jpg"
- Source URL: https://commons.wikimedia.org/wiki/File:Signing_Of_The_Social_Security_Act.jpg
- Public domain basis: The Commons file page tags the photograph Public domain.

## 3. ss-card.jpg (activity, File 1)

- Title: Photograph of a Social Security Card
- What it shows: An early Social Security card, enlarged.
- Creator: Unknown author, Social Security Board records
- Date: Between 1936 and 1948, as dated on the Commons file page
- Repository: National Archives and Records Administration, National Archives ID 595679, Record Group 47, Records of the Social Security Administration, via Wikimedia Commons, file "Photograph of a Social Security Card, NARA 595679"
- Source URL: https://commons.wikimedia.org/wiki/File:Photograph_of_a_Social_Security_Card_-_NARA_-_595679.gif
- Public domain basis: Work of the United States federal government held by the National Archives; the Commons file page tags it Public domain. The card number in the photograph is a specimen number, not a person's assigned number.

## 4. lange-lumber.jpg (quick check figure; deck portrait crop)

- Title: Unemployed lumber worker goes with his wife to the bean harvest. Note Social Security number tattooed on his arm. Oregon.
- What it shows: An unemployed lumber worker seated with his wife in a migrant camp near West Stayton, Oregon; his Social Security number is tattooed on his upper arm. Verified by inspection of the downloaded file.
- Creator: Dorothea Lange
- Date: August 1939
- Repository: Library of Congress, Prints and Photographs Division, Farm Security Administration collection, digital ID fsa.8b15572, via Wikimedia Commons, file "Dorothea Lange, Unemployed lumber 01"
- Source URL: https://commons.wikimedia.org/wiki/File:Dorothea_Lange_-_Unemployed_lumber_01.jpg
- Public domain basis: Photograph made for the Farm Security Administration, a United States federal agency; the Commons file page tags it Public domain.

## 5. holc-map.jpg (activity, File 4; deck portrait crop)

- Title: Home Owners' Loan Corporation security map, 1937
- What it shows: A city map divided into graded residential areas, the map form federal housing officials used in the late 1930s to grade neighborhoods for lending risk. The Commons file description, drawn from the University of Pennsylvania redlining archive, does not name the city in the text retrieved for this build, so the documents do not name one either.
- Creator: United States Federal Government, Home Owners' Loan Corporation
- Date: 1937
- Repository: Records of the Federal Home Loan Bank Board (Record Group 195), National Archives II, via Wikimedia Commons, file "Holc redlining 1937"
- Source URL: https://commons.wikimedia.org/wiki/File:Holc_redlining_1937.jpeg
- Public domain basis: Work of the United States federal government; the Commons file page tags it Public domain.
