# Image Sources: Lesson 3, Roosevelt and the First Hundred Days

All images are public domain as stated on their Wikimedia Commons file pages. Downloads were made from Wikimedia Commons on October 21, 2026, and each file was verified as a valid image with PIL. Original downloads live in assets/. Deck crops live in slides-build/img/ and were cropped from the downloads listed here.

- Title: Franklin D. Roosevelt's First Inauguration
- Creator: Architect of the Capitol photograph, via USCapitol, as stated on the Commons file page
- Date: March 4, 1933
- Holder: Architect of the Capitol, via Wikimedia Commons
- Source: https://commons.wikimedia.org/wiki/File:Flickr_-_USCapitol_-_Franklin_D._Roosevelt%27s_First_Inauguration.jpg
- Public domain basis: Commons file page marks the image Public domain; it is an official photograph of the United States federal government (Architect of the Capitol).
