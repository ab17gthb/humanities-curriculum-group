## Image

- Title: A Map of the British and French Dominions in North America, with the roads, distances, limits, and extent of the settlements (the Mitchell Map)
- What it actually is: John Mitchell's eight-sheet map of North America, the most important map of the continent made in the colonial period, drawn from official records and surveys and dedicated to the Earl of Halifax and the Lords Commissioners for Trade and Plantations. The cover shows the joined map whole: Hudson Bay and the inset of Hudson's Bay at upper left, New France and the Great Lakes across the top, the Atlantic seaboard colonies at center right, Louisiana along the bottom, and Mitchell's dedication cartouche at lower right. The same map ships in the unit itself, in Lesson 8 (img/mitchell-map.jpg; the lesson's deck crops mitchell-port.jpg and the title image title-169.jpg derive from it), where the lesson's SOURCES.md carries its full record.
- Creator: John Mitchell (1711 to 1768), cartographer
- Date: first published in London in 1755 (the Library of Congress copy of the joined map is dated 1755; the Commons file page dates this impression 1757)
- Repository: Library of Congress, Geography and Map Division
- Identifiers: Library of Congress item 74693173, call number G3300 1755 .M51, digital ID g3300.ar004000; Wikimedia Commons file Mitchell_Map-06full2.jpg
- Public domain basis: An eighteenth century printed work whose creator died in 1768. The Wikimedia Commons file page tags the file "Public domain," verified through the Commons API during this build (license field: Public domain), and the unit's Lesson 8 SOURCES.md records the same verification. The record was also opened directly at the Library of Congress for this cover (item 74693173, call number and repository as above).
- The copy held locally is covers/mitchell-map-1755.jpg (3840 x 2713), downloaded fresh from the Commons file for this cover at the same dimensions the unit build recorded for its own download. Because a full-resolution original crashed the headless renderer in the World War II cover build, the cover HTML renders from a downscaled copy, covers/mitchell-map-1755-cover.jpg (2560 x 1809); no visual difference at cover size. The cover frame crop (object-fit: cover, object-position center 38%) holds the whole joined map with the cartouche visible; visually checked.
