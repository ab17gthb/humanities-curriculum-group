# Lesson 2 deck images: sources

All images are real public domain images, derivative crops of the lesson assets in `lesson-02/assets/` (see `lesson-02/img/SOURCES.md` for the full catalog records). No AI-generated or stock-site images. Portrait files are crops made with PIL from the sources below, resized to 1046 by 1500 pixels for the right-side photo slots in deck_common; the title file is a 16:9 crop resized to 1600 by 900. Cropping only; nothing stretched.

  - Title: Grauman's Chinese Theatre, Hollywood
  - Creator: Unknown photographer
  - Date: 1927
  - Repository: Wikimedia Commons
  - Source URL: https://commons.wikimedia.org/wiki/File:Graumans_Chinese_Theatre_1927.jpg
