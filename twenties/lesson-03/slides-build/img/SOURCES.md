# Lesson 3 deck images: sources

All images are real public domain images via Wikimedia Commons, the Library of Congress, the State Library of Queensland, the Seattle Municipal Archives, the Digital Public Library of America, or the Internet Archive. No AI-generated or stock-site images. Portrait files are center crops made with PIL from the lesson assets below, resized to 1046 by 1500 pixels for the right-side photo slots in deck_common; the title file is a 16:9 crop resized to 1920 by 1080. Cropping only; nothing stretched.
